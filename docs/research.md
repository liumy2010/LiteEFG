# Paper and citation

LiteEFG implements game-solving algorithms as local computation graphs, using a Python interface and a C++ execution engine. The [LiteEFG paper](https://arxiv.org/abs/2407.20351) describes the design and experimental motivation.

## Cite LiteEFG

If you use LiteEFG in your research, please cite:

```bibtex
@article{liu2024liteefgefficientpythonlibrary,
  title={{LiteEFG}: An Efficient Python Library for Solving Extensive-form Games},
  author={Mingyang Liu and Gabriele Farina and Asuman Ozdaglar},
  year={2024},
  eprint={2407.20351},
  archivePrefix={arXiv},
  primaryClass={cs.GT},
  url={https://arxiv.org/abs/2407.20351}
}
```
